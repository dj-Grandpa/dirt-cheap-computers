## 1. Seed Computer v0.1 - $0.10

Charcoal + salt water + foil on cardboard. Soil battery with 2 rusty nails (0.6V). Pencil graphite wire. 1-bit memory that remembers after power off.

Materials: cardboard, charcoal from fire, salt, aluminum foil, pencil, 2 nails, dirt, water.

How: Draw circuit with pencil. Foil = capacitor. Charcoal+salt = transistor. Dirt battery powers it.

## 2. Light Brick - $0.10

Mud + ash + straw + bottle glass melted in sun. Charcoal transistor dots. Computes with sunlight, no wires.

Materials: mud, wood ash, straw, broken bottle glass, charcoal.

How: Sun lens melts glass into light pipes. Charcoal dots block/allow light = transistor. Sun = power and clock.

## 3. Notebook Computer - $1

100-page school notebook, pencil, wax, foil, lemons. 10,000 transistors. Lemon battery. Stores for 20 years.

Materials: notebook, pencil, candle wax, foil, 3 lemons, nails, copper wire.

How: Each page = circuit layer. Wax + foil = capacitor. Pencil + charcoal = transistor. Lemon battery = 2.4V. Write 256 bytes per page.
