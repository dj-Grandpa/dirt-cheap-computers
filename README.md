## 1. Seed Computer v0.1 - $0.10
Charcoal + salt water + foil on cardboard. Soil battery with 2 rusty nails (0.6V). Pencil graphite wire. 1-bit memory.

## 2. Light Brick - $0.10  
Mud + ash + straw + bottle glass melted in sun. Charcoal transistor dots. Computes with sunlight.

## 3. Notebook Computer - $1
100-page school notebook, pencil, wax, foil, lemons. 10,000 transistors. Lemon battery. 20 year storage.
